Clash data folder

This project reads and writes all its clash data in one folder you choose. The folder is remembered inside the Revit model, so everyone who opens the model uses the same folder. Point it at a different folder and you see that folder's data; an empty folder shows nothing.
FolderNot set
No folder set, so no clash data is shown. Click “Set up folder” and pick this project's clash data folder.
The folder is remembered on this machine, but the model hasn't been saved since it was set - save the model so teammates get the folder too.

Linked model roles

Clash tests only see linked models that are mapped to a role. An unmapped link is skipped, so clashes against its elements are never found.
Linked model(s) set to (ignore) are not tested. Re-run your tests after changing a role.
